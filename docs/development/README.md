# Разработка

Общие инструменты и материалы для подготовки новых руководств:

- [Инструменты Windows, macOS и Linux](host-tools.md).
- [Windows-автоматизация: интерфейсы и проверки](windows-automation.md).
- [Камерные работы AR0234 и IMX296](cameras.md).

Готовое решение переносится в `docs/guides` после проверки команд на SBC.
Руководство должно содержать цель, применимую конфигурацию, версии входных
файлов, последовательность действий и признаки успешного результата.
Аппаратная проверка фиксируется отдельно от CI и сборки.

Ближайшие дополнения: аппаратные маршруты EDL с macOS/Linux, публичный комплект
файлов прошивки, расширение Android `/data`, настройка Ethernet и камеры.
