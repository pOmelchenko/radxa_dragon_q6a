# Файлы прошивки и контроль целостности

Git хранит инструкции, исходники и патчи. Полная прошивка, утилита EDL,
программаторы, исправленные XBL/SPI и аппаратные бэкапы собраны отдельно:

```text
Q6A-Android15-UFS-Toshiba-512.zip
1697316624 bytes
SHA256 94cf5947c6d6af85ea499108d8b74d6e4c3d6c86abf1521b75ca05bf2970008a
```

Архив уже создан и проверен локально. Ссылки на опубликованный GitHub Release
пока нет: готовые бинарные пакеты ещё не опубликованы в release. Для первого запуска
возьмите сохранённый ZIP или его распакованный каталог. Перед публикацией
пакета нужно отдельно подготовить его публичный состав: текущий личный архив
содержит оригинальные логи и бэкапы конкретной платы.

## Пакет Linux BIOS

Для прямого Linux rawprogram отдельно сохранены все 23 нужных файла:

```text
Q6A-Linux-BIOS-tested-files.zip
11067838 bytes
SHA256 49a615adbad48c6af558825bc1d72e3ee1be62ec2a49f8480e11552a04507497
```

Архив содержит каталог `linux-bios/`: rawprogram, patch, DDR программатор и
все непустые filename из Linux XML. Его CRC и SHA-256 каждого payload проверены.
Хеши файлов и архива: [linux-bios-files.json](../manifests/linux-bios-files.json).
При распаковке получите самостоятельные копии, затем следуйте
[прямой инструкции Linux](linux-bios.md). Этот архив не меняет Android пакет.

Основной путь проверяет распакованные файлы прямыми PowerShell командами в
[direct-edl.md](direct-edl.md). Вспомогательное подключение пакета ниже проверено
без платы и также не выполняет прошивку.

## Подключить пакет вспомогательным скриптом

Из корня репозитория:

```powershell
& .\scripts\Prepare-Bundle.ps1 -Source 'D:\firmware\Q6A-Android15-UFS-Toshiba-512.zip'
```

Скрипт сверяет хеш архива, проверяет доступное место, распаковывает файлы в
`artifacts/`, затем проверяет хеш manifest и все файлы пакета.
Путь к проверенному каталогу сохраняется в `artifacts/bundle-path.txt`.
Каталог `artifacts/` исключён из Git.

Если каталог уже распакован, повторное копирование не требуется:

```powershell
& .\scripts\Prepare-Bundle.ps1 -Source 'D:\firmware\Q6A-Android15-UFS-Toshiba-512'
& .\scripts\Install-Q6A-Android.ps1 -Stage Check
```

На другой машине снова выполните Prepare-Bundle со своим путём. Для разового
вызова установщика можно передать `-Bundle <path>` без сохранённой настройки.
Все проверки здесь выполняются без обращения к USB.

Не пересоздавайте manifest, чтобы принять изменённую прошивку. Lock файл
[manifests/bundle-lock.json](../manifests/bundle-lock.json) задаёт точный пакет
версии 1. Другие релизы требуют отдельного обновления и проверки рецепта.

## Содержимое пакета

| Каталог | Файлы |
| --- | --- |
| `firmware/ufs/asic` | 6 rawprogram XML, 6 patch XML и все используемые образы |
| `firmware/spinor` | Исходные Android SPI файлы и DDR Firehose |
| `tools` | Проверенный edl-ng v2 и сопутствующие файлы |
| `images` | Исправленные XBL и полный SPI 32 МиБ |
| `evidence` | Логи записи, обратного чтения и загрузки |
| `recovery` | Оригинальная Android SPI и сохранённый рабочий Linux BIOS |
| `source` | Снимок исходников прежнего эксперимента |

Пакет содержит 119 файлов плюс manifest, около 4,10 ГБ в распакованном виде.
Все файлы в ZIP проверены по SHA-256 и CRC. Сам архив содержит самостоятельные
копии. В исходном локальном каталоге крупные vendor файлы используют жёсткие
ссылки NTFS: изменение оригинала изменяет и linked файл. Для хранения и
переноса сохраняйте ZIP с его `.sha256`.

## Исходный релиз

Основа пакета — `Q6A-Android15-spi-ufs-boot-20260630-b1` из
[официального каталога Radxa](https://dl.radxa.com/dragon/q6a/images/android/).
Одного повторного скачивания исходной прошивки недостаточно: нужны исправления
EDL и XBL, описанные в [xbl-workaround.md](xbl-workaround.md).

Хеши файлов проекта отдельно проверяет `python scripts/check_repository.py`.
Это проверка документации и исходников; она не заменяет Check готовой прошивки.
