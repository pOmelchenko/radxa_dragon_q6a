# Инструменты для ОС самой Q6A

Эти команды выполняются на SBC после загрузки системы. ОС компьютера,
с которого копируется скрипт, на их работу не влияет. Инструменты хоста
находятся в `tools/common`, `tools/windows`, `tools/linux` и `tools/macos`.

## Linux

[`linux/install-ufs-active-policy.sh`](linux/install-ufs-active-policy.sh)
устанавливает настройку питания для Toshiba `THGJFCT2T84BAKCB` на Q6A.
Проверены Linux BIOS 260916 и ядро Radxa OS R2 `6.18.2-3-qcom`.
Полная последовательность: [установка Linux на UFS](../../docs/guides/linux-ufs.md).

Запускать через `sudo bash`. Скрипт проверяет модель и расположение корня
на физическом UFS LUN 0, применяет настройку udev, включает помощник в
initramfs и проверяет его копию на EFI. Имена `/dev/sd…` не фиксированы.
Существующие файлы принимаются только при полном совпадении содержимого.

Установщик пересобирает initramfs текущего ядра (`uname -r`). При обновлении
версию следующего ядра нужно проверять отдельно по
[общей инструкции Radxa OS](../../docs/guides/linux-update.md#toshiba-ufs-проверить-initramfs-нового-ядра).

Параметр `--defer` устанавливает файлы и пересобирает initramfs, пропуская
применение к текущему сеансу. Для обычной установки используйте запуск
без параметров, который дополнительно проверяет текущие значения.
