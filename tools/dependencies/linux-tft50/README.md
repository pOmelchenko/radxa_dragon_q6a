# EDT FT5x06 для BTT Pi TFT50 V2.1

Закреплённая зависимость для Q6A с ядром **`7.0.11-7-qcom`**.
Результат — отдельный модуль `edt-ft5x06.ko`; исходники ядра целиком,
готовые модули и DTBO в репозитории не хранятся.

| Вход | Происхождение |
| --- | --- |
| Базовый драйвер | [Linux stable v7.0.11](https://github.com/gregkh/linux/blob/v7.0.11/drivers/input/touchscreen/edt-ft5x06.c) |
| [0001-input-polling.patch](0001-input-polling.patch) | Marek Vasut, [предложение от 2026-01-09](https://lore.kernel.org/all/20260109035149.1341931-2-marex@nabladev.com/), diff извлечён из [копии письма MARC](https://marc.info/?l=devicetree&m=176793351400798&w=2) |
| [0002-pi-touch-packets.patch](0002-pi-touch-packets.patch) | Локальная адаптация обработки пакетов из [Raspberry Pi `d2afc067c8adfcd6563533ff30cadb41e169aa23`](https://github.com/raspberrypi/linux/commit/d2afc067c8adfcd6563533ff30cadb41e169aa23); исходные изменения Dave Stevenson и Nick Hollinghurst |
| Штатный DTBO | Установленный оверлей Radxa для Raspberry Pi 7-inch; связанный [коммит исходников](https://github.com/radxa-pkg/radxa-overlays/commit/fbcee0ab93d04b07df0ed153b0ce68005c460e31) |
| Лицензия драйвера и производных патчей | `GPL-2.0`, [оригинал текста из Linux](GPL-2.0) |
| Точные входы и результаты | [source.lock.json](source.lock.json): URL, дата получения, SHA-256, порядок патчей и контрольные суммы после каждого шага |

Первый патч включает `input_setup_polling()` с периодом 17 мс, если DT
не назначает IRQ. Это опубликованное предложение; его наличие в штатном
ядре не предполагается. Второй патч читает сначала заголовок и `TD_STATUS`,
затем только активные точки, фильтрует начальное устаревшее состояние,
проверяет границы ID и отпускает исчезнувшие контакты. Одного первого
патча на проверенном TFT50 оказалось недостаточно.

Ветка Raspberry Pi использована как источник логики пакетов. Её собственная
реализация таймера целиком не переносилась. SHA-256 файла, полученного
первоначально из `rpi-6.12.y`, совпал с файлом закреплённого коммита.
Второй патч сохранён без правок после аппаратной проверки, включая форматирование.

Сборка проверяет каждый вход, промежуточный исходник и итоговый исходник.
Проверка `check-repo` сверяет патчи, лицензию и источник power overlay.
Готовый модуль устанавливается поверх штатного через `updates/q6a-tft50/`
только для указанного ядра. DKMS и автоматической сборки при обновлении
ядра здесь нет. Другие FT5x06, factory mode, suspend/resume и multitouch
этой проверкой не квалифицированы.
