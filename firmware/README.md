# Описания прошивок

Здесь хранятся закреплённые входные данные инструментов: размеры, SHA-256,
параметры XBL и сохранённых SPI-образов. Образы и программаторы размещаются
локально и не входят в Git.

Назначение файлов и получение комплектов:
[справочник прошивок](../docs/reference/firmware-files.md).
